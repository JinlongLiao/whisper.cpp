# 粤语与台语模型下载及使用说明

核对日期：2026-10-23。以下为 Whisper 架构微调模型，提供用于 `whisper.cpp` 的 GGML 文件。下载脚本仅下载权重，不更换本地原生库，也不修改测试的默认模型。

## 下载方式

需要 Bash、curl，以及 `shasum` 或 `sha256sum`。macOS 通常已有这些工具。

在当前 Java 项目目录运行：

```bash
# 列出支持的编号；无参数也只显示列表。
bash download-dialect-model.sh --list

# 粤语 Small：约 190 MB。
bash download-dialect-model.sh yue-small-q5_1

# 粤语 Base：约 148 MB。
bash download-dialect-model.sh yue-base

# 台湾华语：约 874 MB。
bash download-dialect-model.sh zh-tw-turbo-q8_0

# 台语／闽南语：约 1.08 GB。
bash download-dialect-model.sh nan-breeze26-q5_0
```

目标目录固定为**脚本所在目录下的 `model/`**，本项目对应：

```text
/Users/thinking/workspace/opensource/whisper/bindings/java/model/
```

从其他工作目录通过绝对路径调用脚本，目标目录也不会改变。模型二进制和下载临时文件由 `model/.gitignore` 排除。

脚本固定 Hugging Face revision 和 SHA-256，校验通过的已有文件直接复用；缺失或不匹配时重新下载。下载先写同目录临时文件，完成大小及 SHA-256 校验后才替换目标。失败返回非零状态，清理本次临时文件，保留已有目标文件。脚本不提供断点续传。

## 在当前项目中加载

在 Java 中传入下载后的实际路径，例如：

```java
try (WhisperCpp whisperCpp = new WhisperCpp()) {
    whisperCpp.initContext("model/ggml-small-cantonese-q5_1-v1.bin");
    // 后续传入 16 kHz 单声道 PCM，调用转写或候选语种概率接口。
}
```

上述相对路径以 Java 进程的工作目录为准；IDE 工作目录应设置为当前 `bindings/java`，也可以使用模型绝对路径。

当前 `WhisperLanguageDetectionTest.resolveLanguageDetectionModel()` 固定读取 `../../models/ggml-tiny.bin`，不读取 `whisper.test.model`。本次只新增文档和下载工具，没有改变这一测试配置；下载专用模型后需在相应测试中显式选用新路径。

`testDetectAudioLanguage` 使用英文 JFK 音频并断言 `en`，属于通用模型回归测试；不能用它来判定粤语或台语微调模型的质量。专用模型应使用相应语言的真实录音分别评估。麦克风测试需显式启用 `whisper.test.microphone=true`，并允许终端或 IDE 使用麦克风。

如果已编译仓库的 CLI，可在当前 Java 项目目录使用真实粤语录音验证转写：

```bash
../../build/bin/whisper-cli \
  -m model/ggml-small-cantonese-q5_1-v1.bin \
  -f /path/to/cantonese.wav -l zh
```

该 Small 上游示例使用 `zh`，量化发布者报告也试过 `yue`。应结合模型 tokenizer 与实际输出比较，不把 `yue` 可选误认为自动语种检测已经验证。

## 能力与验证边界

- **转写和语种检测分开评估。** 微调模型的转写 CER 更低，不能证明候选语种概率更可靠。上述专用模型尚未在当前 Java 绑定中完成加载和识别验收。
- 粤语 Small 原作者报告 Common Voice 16.0 去标点 CER 为 7.93%；这不是 Q5_1 量化版的验证结果。量化发布者只报告过小样本加载及转写测试。
- 台湾华语不是台语。台湾华语一般属于 `zh`；台语／闽南语是另一种语言。
- 当前项目原生语种表有 `zh`、`yue`，没有独立 `nan`。下载台语模型不会使现有概率接口自动返回独立的台语标签。Small/Base 微调模型也需核对自身 tokenizer 与语种输出，不能只看本地库存在 `yue` 名称就认为检测有效。
- Breeze-ASR-26 以约一万小时合成台语数据微调，输出国语汉字而非台语正字；GGML 发布者的量化比较以 HF 输出作伪参考，不是人工标注准确率。
- 模型卡标注：粤语 Base／Small 及 Breeze-ASR-26 为 Apache-2.0，台湾华语 Turbo GGML 为 MIT。再分发时应核对并保留原作者及转换者的许可证和归属信息。
