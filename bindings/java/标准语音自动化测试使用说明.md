# 标准语音自动化测试使用说明

本流程比较 Tiny、Base、Orbination Q3_K／Q4_K／Q5_K 的语种识别、转写文本、文本错误率和耗时。所有推理在本机运行；自动输出本地报告，不向外部服务发送测试音频或报告。

## 一键运行

在 `bindings/java` 目录执行：

```bash
# ffmpeg 已在 PATH 时可省略这一行；以下为本机实际路径。
export FFMPEG=/Users/thinking/Applications/utils/ffmpeg/ffmpeg
bash 运行标准语音测试.sh
```

脚本顺序：检查 Python 3、FFmpeg 和 whisper-cli → 下载缺失的 Tiny／Base → 校验并复用或下载三个 Orbination 模型 → 下载固定音频及参考稿 → 串行测试 → 自动生成 Markdown 和 CSV 报告。首次运行会下载约 1.7 GB 模型，另需少量音频下载流量；模型已存在时复用。Orbination 由既有下载器核对文件大小及 SHA-256；官方 Tiny／Base 下载器仅检查文件存在，不提供同等级的完整性校验。

失败时命令返回非零状态，完整日志写入 `target/standard-automation-时间戳.log`；原生推理的每轮日志另保存在结果目录。未完成的测试不会生成新的完整汇总报告；已有旧报告不会删除，应以本次命令是否成功及本次日志为准。入口用 `target/standard-automation.lock/` 原子目录锁阻止并发测试和报告重建。若进程被强制终止而留下锁，确认没有测试进程后，执行 `rmdir target/standard-automation.lock`；不要在运行过程中删除结果目录。直接运行 Python 脚本不经过该入口锁，勿与入口并发执行。

## 环境准备

需要 Python 3（仅标准库，无需 pip）、Bash、curl、FFmpeg，以及当前仓库构建出的 `../../build/bin/whisper-cli`。如果尚未构建，以下命令从 `bindings/java` 执行：

```bash
cmake -S ../.. -B ../../build -DCMAKE_BUILD_TYPE=Release
cmake --build ../../build --config Release -j --target whisper-cli
```

macOS 测试使用 Metal，需要允许本机 GPU 访问。测试脚本不自动编译，也不会自动安装系统依赖。

五个固定模型路径：

| 模型 | 相对 bindings/java 的路径 | 手动下载命令 |
|---|---|---|
| Tiny（多语种） | `../../models/ggml-tiny.bin` | `bash ../../models/download-ggml-model.sh tiny` |
| Base（多语种） | `../../models/ggml-base.bin` | `bash ../../models/download-ggml-model.sh base` |
| Orbination Q3_K | `model/ggml-orbination-turbo-q3_k.bin` | `bash download-dialect-model.sh orbination-q3_k` |
| Orbination Q4_K | `model/ggml-orbination-turbo-q4_k.bin` | `bash download-dialect-model.sh orbination-q4_k` |
| Orbination Q5_K | `model/ggml-orbination-turbo-q5_k.bin` | `bash download-dialect-model.sh orbination-q5_k` |

模型来源、发布日期及量化差异见[模型说明](粤语与台语模型说明.md)。

## 音频下载与参考文案

只下载音频：

```bash
python3 下载标准语音样本.py
```

下载位置固定为脚本旁的 `model/标准语音测试集/`。普通话、英语、日语、韩语各 3 条来自 [Google FLEURS](https://huggingface.co/datasets/google/fleurs) 测试集，许可证 CC-BY-4.0，固定版本 `70bb2e84b976b7e960aa89f1c648e09c59f894dd`，按音频归档顺序取前三条匹配参考稿的样本。流式读取归档，不下载整个数据集。已缓存且版本、SHA-256 校验通过的样本会复用。

粤语另用 [sherpa 官方演示样本及 Ground truth](https://k2-fsa.github.io/sherpa/onnx/qwen3-asr/pretrained.html#cantonese-wav)，不是 FLEURS 样本。该示例音频未单独标明许可证，仅用于本地评测。

| 内容 | 本地位置 |
|---|---|
| 粤语原始音频（16.45 秒） | `model/标准语音测试集/yue-cantonese.wav` |
| 粤语参考文案 | `model/标准语音测试集/yue-cantonese.参考文本.txt` |
| 其他语种参考文案 | 每条 WAV 旁的同名 `.参考文本.txt` |
| 全部音频及参考稿清单 | `model/标准语音测试集/manifest.json` |

粤语音频直接下载：[cantonese.wav](https://k2-fsa.github.io/sherpa/_static/qwen3-asr-0.6b/cantonese.wav)。发布方给出的参考文案如下，保留原有写法：

> 今次寻寻觅觅，终于揾到my princess，肯借个场俾我哋玩。你知啦，喺香港地喺繁忙时间要揾个场嚟拍嘢系非常之难嘅。再一次多谢你哋，亦都好多谢片入边嘅每一个人。下一次我哋斗啲咩好？喺下面留言话我哋知啦。拜拜。

这些是发布方提供的参考稿，不是模型识别结果。FLEURS 的同名文本使用官方规范化参考稿；原始标点版另保存在 JSON 清单的 `original_reference` 字段。

## 单独测试及自动报告

音频和模型已准备好后，可跳过下载阶段：

```bash
export FFMPEG=/Users/thinking/Applications/utils/ffmpeg/ffmpeg
python3 标准语音模型测试.py
```

总共 13 条音频 × 5 模型，每个组合转写 3 次、另做 1 次独立语种检测，即 195 次转写和 65 次语种检测。统一使用自动语种、8 线程、Beam Search 5、关闭 Flash Attention、不继承上下文，不把真实语种提前传给模型。

完成后自动输出：

| 文件或目录 | 内容 |
|---|---|
| `测试结果/标准语音五模型测试报告.md` | 汇总、识别语种／概率、参考稿、完整转写、逐条耗时与错误率 |
| `测试结果/标准语音五模型/逐轮结果.csv` | 可用 Excel 打开的全部 195 轮明细，UTF-8 BOM |
| `测试结果/标准语音五模型/样本清单.tsv` | 音频来源、SHA-256、时长、参考稿 |
| `测试结果/标准语音五模型/results.json` | 汇总原始数据，可重新生成报告 |
| `测试结果/标准语音五模型/<模型>/<样本>/` | 三轮 TXT、JSON、日志及独立语种检测日志 |
| `target/standard-audio-pcm/` | FFmpeg 转换得到的 16 kHz 单声道 PCM WAV |

只根据已有完整结果重新输出报告，不下载、不运行模型：

```bash
bash 运行标准语音测试.sh --report-only
```

该模式检查五模型与全部样本的组合是否齐全、是否均完成三轮；不完整则报错，不输出完整报告。

## 如何解读结果

- 语种识别看 `detected_language`，与真实标签 `expected_language` 对比。`zh`＝中文、`en`＝英语、`ja`＝日语、`ko`＝韩语、`yue`＝粤语。候选概率不等于识别准确率。
- 英语计算 WER，其他语种计算 CER；数值越低越好。统一 NFKC、转小写、去除标点，CER 另去空格。不转换简繁和数字读法，这些差异也会计错。汇总按参考字符数或词数加权，使用第一轮完整转写；其他两轮保留供核对。
- 转写耗时取三轮原生 `total time - load time` 的中位数，包含自动语种检测和部分初始化，不含 FFmpeg 解码。每轮为独立进程，不能直接当作 Java 常驻模型的纯推理耗时。CSV 另列加载时间与进程端到端时间。
- Tiny／Base 没有独立粤语标签。当前这一条粤语样本，三个 Orbination 也返回 `zh`；不能把单条结果推广为所有粤语音频的表现。
- 本批是短样本冒烟测试，不是整个 FLEURS 测试集的正式基准。原先用户提供的 `cn_cantonese.opus` 已确认是空音频，未加入本次语音准确性评测。

## Git 忽略范围

本模块 `.gitignore` 忽略 `target/`、Python 缓存和 `测试结果/` 下的原始数据子目录，保留该目录顶层的 Markdown 报告。`model/.gitignore` 保留已有模型／音频忽略规则，并额外忽略整个 `标准语音测试集/`，包括下载的参考稿和清单。

仅调整忽略规则，不删除本地数据，也不执行提交、推送或取消跟踪。已经被 Git 跟踪的文件不受 `.gitignore` 影响。

粤语自动／强制语种对照见[粤语语种识别调用排查报告](测试结果/粤语语种识别调用排查报告.md)。当前模块额外忽略整个 `model/` 数据目录。
